TP1.1 Chiffrement AES-256-GCM et ChaCha20-Poly1305

⏱ 30 min 📋 Python 3.10+, cryptography

Implémenter le chiffrement symétrique AEAD avec les deux algorithmes recommandés, mesurer et comparer leurs performances.

1 Chiffrement AES-256-GCM — Implémentation de base

Créer le fichier aes_gcm.py :

# Créer le fichier
nano ~/crypto_tp/aes_gcm.py
# ── Contenu de aes_gcm.py ──────────────────────────────────────────────
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os, time

# 1. Génération de la clé AES-256 (32 octets = 256 bits)
key = AESGCM.generate_key(bit_length=256)
print(f"Clé AES-256 (hex) : {key.hex()}")
print(f"Taille clé        : {len(key)*8} bits")

# 2. Création de l'objet AESGCM
aesgcm = AESGCM(key)

# 3. Nonce unique 96 bits (12 octets) — JAMAIS réutiliser !
nonce = os.urandom(12)
print(f"Nonce (hex)       : {nonce.hex()}")

# 4. Message à chiffrer
plaintext = b"Virement 5000 DH - Compte: MA76000000000000000000"
aad = b"transaction_id:TXN-2025-001"  # non chiffré, authentifié

# 5. Chiffrement
t0 = time.perf_counter()
ciphertext = aesgcm.encrypt(nonce, plaintext, aad)
t1 = time.perf_counter()
print(f"\nMessage clair     : {plaintext}")
print(f"Message chiffré   : {ciphertext.hex()}")
print(f"Taille chiffré    : {len(ciphertext)} octets (= {len(plaintext)}+16 tag)")
print(f"Temps chiffrement : {(t1-t0)*1e6:.2f} µs")

# 6. Déchiffrement
recovered = aesgcm.decrypt(nonce, ciphertext, aad)
print(f"\nMessage récupéré  : {recovered}")
print(f"Intégrité         : {'✅ OK' if recovered == plaintext else '❌ ERREUR'}")

# 7. Test de détection d'altération
print("\n--- Test altération du message chiffré ---")
tampered = bytearray(ciphertext)
tampered[5] ^= 0xFF
try:
    aesgcm.decrypt(nonce, bytes(tampered), aad)
    print("❌ ERREUR : altération non détectée !")
except Exception as e:
    print(f"✅ Altération détectée : {type(e).__name__}")

3 Benchmark AES-GCM vs ChaCha20 sur un fichier de 10 Mo

nano ~/crypto_tp/bench.py
# ── Contenu de bench.py ─────────────────────────────────────────────────
from cryptography.hazmat.primitives.ciphers.aead import AESGCM, ChaCha20Poly1305
import os, time

SIZE_MB = 10
data = os.urandom(SIZE_MB * 1024 * 1024)

def bench(algo_class, bit_length, name):
    if algo_class.__name__ == "ChaCha20Poly1305":
        key = algo_class.generate_key()          # taille fixe 256 bits
    else:
        key = algo_class.generate_key(bit_length=bit_length)
    algo  = algo_class(key)
    nonce = os.urandom(12)
    t0 = time.perf_counter()
    ct = algo.encrypt(nonce, data, None)
    t1 = time.perf_counter()
    t2 = time.perf_counter()
    algo.decrypt(nonce, ct, None)
    t3 = time.perf_counter()
    enc_speed = SIZE_MB / (t1 - t0)
    dec_speed = SIZE_MB / (t3 - t2)
    print(f"{name:30s} | Chiffrement: {enc_speed:6.1f} Mo/s | Déchiffrement: {dec_speed:6.1f} Mo/s")

print(f"{'Algorithme':30s} | {'Chiffrement':20s} | Déchiffrement")
print("-" * 75)
bench(AESGCM,           256, "AES-256-GCM")
bench(ChaCha20Poly1305, 256, "ChaCha20-Poly1305")
python3 ~/crypto_tp/bench.py

TP1.2 Hachage et Stockage Sécurisé des Mots de Passe

⏱ 20 min 📋 Python 3.10+, hashlib, passlib, argon2-cffi

1 Démonstration de l'insécurité de SHA-256 brut — Rainbow Table

nano ~/crypto_tp/hash_demo.py
# ── Contenu de hash_demo.py ──────────────────────────────────────────────
import hashlib, time

# Base de données vulnérable (SHA-256 brut sans sel)
user_db_insecure = {
    'alice': hashlib.sha256(b'password123').hexdigest(),
    'bob':   hashlib.sha256(b'azerty').hexdigest(),
    'carol': hashlib.sha256(b'letmein').hexdigest(),
}
print("=== Base vulnérable (SHA-256 sans sel) ===")
for user, h in user_db_insecure.items():
    print(f"  {user}: {h[:32]}...")

# Attaque par dictionnaire (simulation rainbow table)
wordlist = ['password', 'password123', '123456', 'azerty', 'letmein',
            'qwerty', 'admin', 'motdepasse', 'soleil', 'football']
print("\n=== Attaque dictionnaire (rainbow table) ===")
cracked = 0
t0 = time.perf_counter()
for word in wordlist:
    h = hashlib.sha256(word.encode()).hexdigest()
    for user, stored_hash in user_db_insecure.items():
        if h == stored_hash:
            print(f"  ✅ CRACKÉ : {user} → '{word}'")
            cracked += 1
t1 = time.perf_counter()
print(f"Résultat : {cracked}/3 comptes crackés en {(t1-t0)*1000:.2f} ms")
python3 ~/crypto_tp/hash_demo.py

2 Stockage sécurisé avec Argon2id — la solution correcte

nano ~/crypto_tp/argon2_demo.py
# ── Contenu de argon2_demo.py ────────────────────────────────────────────
from passlib.hash import argon2
import time, hashlib

# Paramètres Argon2id recommandés (NIST SP 800-63B)
hasher = argon2.using(memory_cost=65536, time_cost=3, parallelism=4)
password = 'MonSuperMotDePasse2025!'

print("=== Hachage Argon2id ===")
t0 = time.perf_counter()
hashed = hasher.hash(password)
t1 = time.perf_counter()
print(f"Hash Argon2id :\n  {hashed}")
print(f"Temps de hachage : {(t1-t0)*1000:.0f} ms  ← intentionnellement LENT")
print(f"Taille du hash   : {len(hashed)} caractères (contient le sel intégré)")

print("\n=== Vérification ===")
ok    = argon2.verify(password, hashed)
wrong = argon2.verify('mauvais_mdp', hashed)
print(f"Mot de passe correct    : {'✅ Oui' if ok else '❌ Non'}")
print(f"Mauvais mot de passe    : {'✅ Refusé' if not wrong else '❌ Accepté !!!'}")

print("\n=== Unicité grâce au sel aléatoire ===")
h1_val = hasher.hash(password)
h2_val = hasher.hash(password)
print(f"Hash 1 : ...{h1_val[-20:]}")
print(f"Hash 2 : ...{h2_val[-20:]}")
print(f"Identiques ? {'OUI' if h1_val == h2_val else '✅ NON — sel aléatoire différent'}")

print("\n=== Comparaison des temps (attaque brute force) ===")
t0 = time.perf_counter()
for _ in range(100000):
    hashlib.sha256(b'tentative').hexdigest()
t1 = time.perf_counter()
print(f"SHA-256 : 100 000 tentatives en {t1-t0:.3f}s → {100000/(t1-t0):.0f} hash/s")
t0 = time.perf_counter()
for _ in range(5):
    hasher.hash('tentative')
t1 = time.perf_counter()
argon_rate = 5/(t1-t0)
print(f"Argon2id: 5 tentatives en {t1-t0:.3f}s → {argon_rate:.1f} hash/s")
print(f"Argon2id est {int(100000/(t1-t0)/argon_rate)}× plus difficile à brute-forcer")
python3 ~/crypto_tp/argon2_demo.py

TP1.3 Génération d'une PKI locale avec OpenSSL

⏱ 30 min 📋 OpenSSL 3.x, terminal Linux

Construire une chaîne de confiance complète — Root CA → CA Intermédiaire → Certificat serveur — en reproduisant ce que font les grandes CAs comme Let's Encrypt.

🏛️ Root CA
autosignée
→ signe
🔗 CA Intermédiaire
signée par Root
→ signe
🌐 Certificat Serveur
www.fst-settat.ma
ℹ️
Toutes les commandes ci-dessous sont à exécuter dans le terminal. Créer d'abord l'arborescence de travail.

1 Créer l'arborescence PKI

mkdir -p ~/crypto_tp/pki/{root-ca,intermediate-ca,certs,csr,private}
cd ~/crypto_tp/pki
touch root-ca/index.txt intermediate-ca/index.txt
echo '1000' > root-ca/serial
echo '2000' > intermediate-ca/serial
chmod 700 private/
echo "Arborescence PKI créée"

2 Générer la Root CA (autosignée)

La Root CA est le sommet de la hiérarchie. Sa clé privée ne sort jamais et son certificat est autosigné.

# 2a. Clé privée Root CA (ECDSA P-384 — haute sécurité)
openssl ecparam -name secp384r1 -genkey -noout -out private/rootca.key.pem
chmod 400 private/rootca.key.pem
echo "✅ Clé privée Root CA générée"

# 2b. Certificat Root CA autosigné (valide 10 ans)
openssl req -new -x509 -days 3650 \
  -key private/rootca.key.pem \
  -out root-ca/rootca.cert.pem \
  -subj "/C=MA/ST=Casablanca/O=FST Settat Root CA/CN=FST Root CA"
echo "✅ Certificat Root CA créé (valide 10 ans)"

# 2c. Vérifier le certificat Root CA
openssl x509 -noout -text -in root-ca/rootca.cert.pem | head -30
✅
Champs à vérifier : Issuer = Subject (autosigné), CA:TRUE, Curve: secp384r1

3 Générer la CA Intermédiaire

# 3a. Clé privée CA Intermédiaire (ECDSA P-256)
openssl ecparam -name prime256v1 -genkey -noout -out private/intermediate.key.pem
chmod 400 private/intermediate.key.pem

# 3b. CSR (Certificate Signing Request)
openssl req -new \
  -key private/intermediate.key.pem \
  -out csr/intermediate.csr.pem \
  -subj "/C=MA/ST=Casablanca/O=FST Settat/CN=FST Intermediate CA"

# 3c. Signer avec la Root CA (valide 5 ans, extension CA:TRUE)
openssl x509 -req -days 1825 \
  -in csr/intermediate.csr.pem \
  -CA root-ca/rootca.cert.pem \
  -CAkey private/rootca.key.pem \
  -CAcreateserial \
  -out intermediate-ca/intermediate.cert.pem \
  -extfile <(echo "[v3_ca]\nsubjectKeyIdentifier=hash\nauthorityKeyIdentifier=keyid,issuer\nbasicConstraints=critical,CA:TRUE,pathlen:0\nkeyUsage=critical,keyCertSign,cRLSign") \
  -extensions v3_ca
echo "✅ CA Intermédiaire signée par Root CA"

4 Générer le certificat serveur final

# 4a. Clé privée du serveur (ECDSA P-256)
openssl ecparam -name prime256v1 -genkey -noout -out private/www.fst-settat.ma.key.pem

# 4b. CSR avec SAN (Subject Alternative Names)
openssl req -new \
  -key private/www.fst-settat.ma.key.pem \
  -out csr/www.fst-settat.ma.csr.pem \
  -subj "/C=MA/ST=Casablanca/O=FST Settat/CN=www.fst-settat.ma"

# 4c. Signer avec la CA intermédiaire (90 jours — comme Let's Encrypt)
openssl x509 -req -days 90 \
  -in csr/www.fst-settat.ma.csr.pem \
  -CA intermediate-ca/intermediate.cert.pem \
  -CAkey private/intermediate.key.pem \
  -CAcreateserial \
  -out certs/www.fst-settat.ma.cert.pem \
  -extfile <(printf "[v3_end]\nsubjectAltName=DNS:www.fst-settat.ma,DNS:fst-settat.ma\nkeyUsage=digitalSignature\nextendedKeyUsage=serverAuth\nbasicConstraints=CA:FALSE") \
  -extensions v3_end
echo "✅ Certificat serveur créé (valide 90 jours)"

5 Vérifier et valider toute la chaîne

# Afficher les sujets et émetteurs
echo "=== Root CA ==="
openssl x509 -noout -subject -issuer -dates -in root-ca/rootca.cert.pem
echo "=== CA Intermédiaire ==="
openssl x509 -noout -subject -issuer -dates -in intermediate-ca/intermediate.cert.pem
echo "=== Certificat Serveur ==="
openssl x509 -noout -subject -issuer -dates -ext subjectAltName -in certs/www.fst-settat.ma.cert.pem

# Vérifier la chaîne de confiance complète
echo "=== Vérification chaîne complète ==="
openssl verify \
  -CAfile root-ca/rootca.cert.pem \
  -untrusted intermediate-ca/intermediate.cert.pem \
  certs/www.fst-settat.ma.cert.pem

subject=C=MA, O=FST Settat Root CA, CN=FST Root CA
issuer=C=MA,  O=FST Settat Root CA, CN=FST Root CA  ← autosigné
---
subject=C=MA, O=FST Settat, CN=FST Intermediate CA
issuer=C=MA,  O=FST Settat Root CA, CN=FST Root CA  ← signée par Root CA
---
subject=C=MA, O=FST Settat, CN=www.fst-settat.ma
issuer=C=MA,  O=FST Settat, CN=FST Intermediate CA  ← signée par Intermediate CA

TP1.4 Signature Numérique Ed25519 en Python

⏱ 15 min 📋 Python 3.10+, cryptography

1 Génération de clés Ed25519 et signature

nano ~/crypto_tp/signature_ed25519.py
# ── Contenu de signature_ed25519.py ──────────────────────────────────────
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.serialization import (
    Encoding, PublicFormat, PrivateFormat, NoEncryption
)

# 1. Génération de la paire de clés Ed25519
private_key = Ed25519PrivateKey.generate()
public_key  = private_key.public_key()
priv_bytes = private_key.private_bytes(Encoding.PEM, PrivateFormat.PKCS8, NoEncryption())
pub_bytes  = public_key.public_bytes(Encoding.PEM, PublicFormat.SubjectPublicKeyInfo)
print("=== Paire de clés Ed25519 générée ===")
print(f"Clé PUBLIQUE (à distribuer) :\n{pub_bytes.decode()}")

# 2. Document à signer
document = b"""ORDRE DE VIREMENT
Emetteur     : Alice Alami
Beneficiaire : FST Settat
Montant      : 2500.00 DH
Date         : 2025-09-06
Reference    : ORD-2025-001"""

# 3. Signature avec la clé privée
signature = private_key.sign(document)
print(f"Taille signature : {len(signature)} octets (Ed25519 = toujours 64 octets)")
print(f"Signature (hex)  : {signature.hex()[:64]}...")

# 4. Vérification — cas normal
print("\n=== Vérification de la signature ===")
try:
    public_key.verify(signature, document)
    print("✅ Signature VALIDE — document authentique et intègre")
except Exception as e:
    print(f"❌ Signature invalide : {e}")

# 5. Test altération du document
print("\n=== Test d'altération ===")
tampered_doc = document.replace(b"2500.00", b"9999.99")
try:
    public_key.verify(signature, tampered_doc)
    print("❌ ERREUR CRITIQUE : altération non détectée !")
except Exception:
    print("✅ Altération détectée — signature INVALIDE sur document modifié")

# 6. Test avec une fausse clé publique
print("\n=== Test avec une fausse clé publique ===")
fake_key = Ed25519PrivateKey.generate().public_key()
try:
    fake_key.verify(signature, document)
    print("❌ ERREUR : fausse clé acceptée !")
except Exception:
    print("✅ Fausse clé rejetée — seule la vraie clé publique peut vérifier")

2 Exécuter

python3 ~/crypto_tp/signature_ed25519.py

✅ Altération détectée — signature INVALIDE sur document modifié
✅ Fausse clé rejetée — seule la vraie clé publique peut vérifier

4 Analyser le handshake TLS 1.3 déchiffré

4a — ClientHello

Développer : TLS 1.3 → Handshake Protocol → Client Hello

🔍 CHAMPS À RELEVER
Version               : TLS 1.2 (0x0303)  ← valeur legacy
Supported Versions    : TLS 1.3 (0x0304)  ← réelle version TLS 1.3
Cipher Suites         : TLS_AES_256_GCM_SHA384
                        TLS_AES_128_GCM_SHA256
                        TLS_CHACHA20_POLY1305_SHA256
Key Share             : curve secp256r1 (P-256) ou x25519
Server Name (SNI)     : example.com

4b — ServerHello

🔍 CHAMPS À RELEVER
Cipher Suite retenue  : TLS_AES_256_GCM_SHA384
Key Share             : clé ECDH du serveur (même courbe que client)
                        → Pre-master secret = ECDH(client_priv, server_pub)

4c — Certificate (déchiffré)

🔍 CHAMPS À RELEVER
Subject               : CN = example.com
Issuer                : CN = DigiCert / Let's Encrypt / ...
Public Key Algorithm  : id-ecPublicKey (ECDSA) ou rsaEncryption (RSA)
Signature Algorithm   : ecdsa-with-SHA256 ou sha256WithRSAEncryption
Subject Alt Names     : DNS:example.com, DNS:www.example.com

4d — RTT du handshake

📐 CALCUL DU RTT
Paquet 1 (→)  ClientHello          t₁ = 0.000000 s
Paquet 2 (←)  ServerHello+Cert     t₂ = 0.012345 s
Paquet 3 (→)  Finished client      t₃ = 0.013100 s
RTT réseau            = t₂ − t₁  =  12.3 ms
RTT total handshake   = t₃ − t₁  =  13.1 ms
TLS 1.2 (2-RTT) ≈ 25–30 ms → TLS 1.3 réduit la latence de ~50 %

🪟 Annexe — Adaptation sous Windows

Ce guide principal est écrit pour Linux. Voici les adaptations pour Windows (WSL ou PowerShell).

TP1.1 — Correction bench.py (TypeError ChaCha20)

Remplacez la ligne 9 :

# AVANT (ligne 9) :
key = algo_class.generate_key(bit_length=bit_length)

# APRÈS :
if algo_class.__name__ == "ChaCha20Poly1305":
    key = algo_class.generate_key()
else:
    key = algo_class.generate_key(bit_length=bit_length)

TP1.2 — Installation passlib

pip install passlib argon2-cffi

TP1.3 — PKI sous Windows

La syntaxe {a,b,c} ne fonctionne pas dans PowerShell. Utilisez :

# PowerShell — depuis le dossier pki :
mkdir root-ca, intermediate-ca, certs, csr, private

Réinitialiser le mot de passe WSL (si oublié) :

# Dans PowerShell :
wsl -u root
# Dans WSL (en root) :
passwd abdel    # remplacer par votre nom d'utilisateur WSL
exit

TP1.5 — SSLKEYLOGFILE sous Windows

Méthode recommandée — Variable système permanente :

Touche Windows → Variables d'environnement → Modifier les variables d'environnement système → Variables d'environnement… → section Variables utilisateur → Nouvelle :

ChampValeur
NomSSLKEYLOGFILE
ValeurC:\Users\<votre_nom>\crypto_tp\tls_keys.log

Puis redémarrer Firefox complètement et vérifier :

# PowerShell :
Get-Content "$env:USERPROFILE\crypto_tp\tls_keys.log"

Méthode complémentaire — about:config Firefox :

Dans la barre d'adresse Firefox : about:config → rechercher security.tls.keylog_file → créer la préférence (type String) et saisir le chemin.

⚠️
Sur Firefox 160.0+, le bouton + pour créer la préférence peut être absent. Dans ce cas, utilisez uniquement la variable système.
